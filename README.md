# Regelfit – Website

Werbe-Website für den Dienst „Regelfit“ (https://regelfit.de). Statische Seiten für GitHub Pages, ohne Build.

- `index.html` – Startseite
- `impressum.html`, `datenschutz.html` – rechtliche Seiten (Entwürfe, nicht anwaltlich geprüft)
- `assets/` – Stile, Schrift Inter (SIL Open Font License 1.1), Favicon

Lokal ansehen: `python3 -m http.server` und `http://localhost:8000` öffnen.

Es wird nichts von fremden Servern geladen: keine Schriften, keine Skripte, keine Analyse.
